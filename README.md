# YaKit-选色

根据 SillyTavern 当前主题和壁纸，筛选容易看清的正文颜色，并生成可复制的 HSL 色域文字；这是 YaKit 系列的酒馆助手脚本。

## 功能特性

- 从底部扩展菜单选择「选色」，测试并自动寻找合适的亮度。
- 根据壁纸、聊天底色和消息底色叠加后的效果筛选颜色。
- 勾选红、橙、金黄、绿、青、蓝、紫、粉，也可以修改各自的色相范围。
- 饱和度、手动亮度和起止色相均可直接填数。
- 正文对比度提供标准与更高两档，下拉列表适配林系配色。
- 查看可用范围、正文样例和对比度，一键复制一句 HSL 色域文字。
- 重复测试时保留当前有效结果，完成后直接更新预览。
- 检测期间控件保持原有颜色，按钮宽度固定。
- 界面沿用 YaKit-Chat 的林系样式，支持桌面和手机。
- 自动更新版每次刷新酒馆或重新启用时检查仓库，加载最新已发布的脚本。

## 安装方法

导入后即可测试当前聊天区，得到一段可直接复制使用的颜色配置，无需填写 API。

1. 下载本仓库的 [YaKit-选色-自动更新.json](dist/YaKit-选色-自动更新.json)。
2. 在酒馆中打开「扩展程序 → 酒馆助手 → 脚本」，点击「导入」。
3. 选择「全局脚本库」，确认后选择刚下载的文件；已安装旧版时先停用旧脚本，并选择覆盖原脚本。
4. 打开「YaKit-选色」旁的启用开关，点击聊天输入框旁的扩展按钮（魔杖图标），选择「选色」。
5. 点击「开始测试」，再点击「复制配置」获取结果。

在线版需要能联网加载脚本。也可选择 [离线版](dist/YaKit-选色.json)，下载导入后即可使用。

已安装 v0.1.4 或更早的自动更新包时，需要覆盖导入一次新版自动更新包，启用新的更新方式。

## 使用说明

1. 在酒馆中打开需要使用颜色的聊天，保持目标主题和壁纸。
2. 打开底部扩展菜单，选择带调色盘图标的「选色」；默认检测全部八个色区，并自动寻找亮度。
3. 按需直接填写饱和度和起止色相，例如把红色设为 `350` 到 `10`；如果只想使用部分颜色，取消勾选其他色区。
4. 展开「正文对比度要求」，选择「4.5 : 1 · 标准」或「7 : 1 · 更高」；也可以聚焦后用键盘选择。
5. 点击「开始测试」，检测期间选项暂时锁定，按钮显示「正在测试…」；完成后查看可用范围、样例及结果预览中的饱和度、亮度和对比度阈值。重复测试时保留当前有效结果，完成后更新预览；若检测失败或设置、背景发生变化，则清空旧结果。需要固定亮度时，取消「自动寻找最佳亮度」后填写亮度并重测。
6. 点击「复制配置」获取一句 HSL 色域文字。若浏览器限制自动复制，文本会被选中，可长按或按 `Ctrl/Cmd+C` 复制。
7. 更换主题、壁纸或可见聊天内容后重新测试；背景变化会使旧结果失效。
8. 自动更新版发布更新后，刷新酒馆或先停用再启用脚本，会重新检查并加载最新版本；离线版更新时需重新下载并覆盖导入。

输出格式如下，实际范围以检测结果为准：

> 选色（HSL色相）：红345–360或0–15、橙15–40、金黄40–65、绿65–165、青165–200、蓝200–260、紫260–300、粉300–345。

## 配置说明

| 设置 | 默认值 | 用法 |
| --- | --- | --- |
| 自动寻找最佳亮度 | 开启 | 在 10%–90% 中寻找可用范围最多的共同亮度 |
| 饱和度 S | 70% | 0%–100%，越高颜色越鲜明 |
| 亮度 L | 50% | 关闭自动亮度后使用，可填写 0%–100% |
| 正文对比度 | 4.5:1 | 可选 7:1，要求更高 |
| 色区 | 全选八色 | 起止范围为 0–360 的整数；起始大于结束表示跨过 0° |

关闭弹窗再打开会保留本次设置；刷新酒馆或重新启用脚本会恢复默认。

## 兼容性

支持 SillyTavern 1.12.13+、酒馆助手 4.9.5+；宿主版本门槛来自酒馆助手，导入格式与脚本启停按 4.9.5 验证。浏览器需要支持原生弹窗、Canvas 和 ES 模块。

支持自定义下拉样式的浏览器会显示林系选项列表和展开动效；其他浏览器使用系统选项列表，仍可正常选择。

适用于标准酒馆的单张壁纸及透明聊天底色。检测是对当前可见正文区域的缩小采样估算；渐变、多层图片、复杂混合滤镜和自定义伪元素背景不在完整支持范围内，动态图仅取读取时的一帧。

默认阈值采用正文的 [WCAG 对比度要求](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum/)；采样结果不等同于整张页面的无障碍认证。

## 常见问题

**为什么某个色区只有一部分可以用？** 只会输出满足当前条件的连续范围，不会用某个代表色替整段色域通过测试。

**为什么没有可用颜色？** 背景的明暗跨度或对比度要求可能过高。可以调整亮度，或提高酒馆聊天底色的不透明度后再测。

**为什么无法读取壁纸？** 图片尚未加载、地址不可达，或图片来源不允许浏览器采样。可以换用上传到酒馆的本地壁纸后重试。

**没有打开聊天可以测试吗？** 可以，会检测当前空聊天区的背景；打开聊天后建议重新测试消息实际显示的底色。

**为什么自动更新版还没更新？** v0.1.4 及更早的自动更新包需要先覆盖导入新版一次。之后刷新酒馆或先停用再启用脚本即可检查更新；正在使用的窗口会在下次加载时更新。仓库也需要先发布新版脚本。

**为什么自动更新版加载失败？** 请确认网络能访问 GitHub。短时间内频繁重新启用可能触发 GitHub 的请求限额，稍后再试；需要立即使用时可导入离线版。

**为什么扩展菜单里没有「选色」？** 确认脚本已启用，并在酒馆加载完成后重新启用。在线版无法加载时，可下载离线版并覆盖导入。
