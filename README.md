# YaKit-选色

根据 SillyTavern 当前主题和壁纸，筛选容易看清的正文颜色，并生成可复制的 HSL 色域文字；这是 YaKit 系列的酒馆助手脚本。

## 功能特性

- 点击悬浮按钮即可测试，自动寻找合适的亮度。
- 根据壁纸、聊天底色和消息底色叠加后的效果筛选颜色。
- 勾选红、橙、金黄、绿、青、蓝、紫、粉，也可以修改各自的色相范围。
- 查看可用范围、正文样例和对比度，一键复制完整色域文字。
- 界面沿用 YaKit-Chat 的林系样式，支持桌面和手机。

## 安装方法

导入后即可测试当前聊天区，得到一段可直接复制使用的颜色配置，无需填写 API。

1. 下载本仓库的 [YaKit-选色.json](dist/YaKit-选色.json)。
2. 在酒馆中打开「扩展程序 → 酒馆助手 → 脚本」，点击「导入」。
3. 选择「全局脚本库」，确认后选择刚下载的文件。
4. 打开「YaKit-选色」旁的启用开关，点击页面右侧的调色盘悬浮按钮。
5. 点击「开始测试」，再点击「复制配置」获取结果。

## 使用说明

1. 在酒馆中打开需要使用颜色的聊天，保持目标主题和壁纸。
2. 点击右侧调色盘，默认检测全部八个色区，并自动寻找亮度。
3. 如果只想使用部分颜色，取消勾选其他色区；也可以改写起止色相，例如把红色设为 `350` 到 `10`。
4. 点击「开始测试」，查看可用范围与样例。需要固定亮度时，取消「自动寻找最佳亮度」后填写亮度并重测。
5. 点击「复制配置」。若浏览器限制自动复制，文本会被选中，可长按或按 `Ctrl/Cmd+C` 复制。
6. 更换主题、壁纸或可见聊天内容后重新测试；背景变化会使旧结果失效。

输出格式如下，实际范围和亮度以检测结果为准：

> 选色（HSL色相）：红345–360或0–15、橙15–40、金黄40–65、绿65–165、青165–200、蓝200–260、紫260–300、粉300–345。使用条件：饱和度70%、亮度80%；当前可见聊天区采样对比度≥4.5:1。

复制文字中的饱和度和亮度需要一起使用。相同色相在不同亮度下，清晰度可能完全不同。

## 配置说明

| 设置 | 默认值 | 用法 |
| --- | --- | --- |
| 自动寻找最佳亮度 | 开启 | 在 10%–90% 中寻找可用范围最多的共同亮度 |
| 饱和度 S | 70% | 0%–100%，越高颜色越鲜明 |
| 亮度 L | 50% | 关闭自动亮度后使用，可填写 0%–100% |
| 正文对比度 | 4.5:1 | 可选 7:1，要求更高 |
| 色区 | 全选八色 | 起止范围为 0–360 的整数；起始大于结束表示跨过 0° |

关闭弹窗再打开会保留本次设置；刷新酒馆或重新启用脚本会恢复默认。

## 兼容性

支持 SillyTavern 1.12.13+、酒馆助手 4.9.5+；宿主版本门槛来自酒馆助手，导入格式与脚本启停按 4.9.5 验证。浏览器需要支持原生弹窗、Canvas 和 ES 模块。

适用于标准酒馆的单张壁纸及透明聊天底色。检测是对当前可见正文区域的缩小采样估算；渐变、多层图片、复杂混合滤镜和自定义伪元素背景不在完整支持范围内，动态图仅取读取时的一帧。

默认阈值采用正文的 [WCAG 对比度要求](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum/)；采样结果不等同于整张页面的无障碍认证。

## 常见问题

**为什么某个色区只有一部分可以用？** 只会输出满足当前条件的连续范围，不会用某个代表色替整段色域通过测试。

**为什么没有可用颜色？** 背景的明暗跨度或对比度要求可能过高。可以调整亮度，或提高酒馆聊天底色的不透明度后再测。

**为什么无法读取壁纸？** 图片尚未加载、地址不可达，或图片来源不允许浏览器采样。可以换用上传到酒馆的本地壁纸后重试。

**没有打开聊天可以测试吗？** 可以，会检测当前空聊天区的背景；打开聊天后建议重新测试消息实际显示的底色。
